# Tenant Management System

A lightweight HTML-based tenant management dashboard for tenant provisioning and data management.

## Features

- Add, edit, and delete tenants
- View tenant directory and statuses
- Track storage usage and monthly revenue
- Manage tenant plans and provisioning workflow
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` directly in a browser.

## Project structure

- `index.html` — main app layout
- `styles.css` — styling
- `script.js` — tenant data logic and interactions

## Notes

This is a front-end demo using in-memory data for quick setup and testing. It can be extended with a real backend or database later.
